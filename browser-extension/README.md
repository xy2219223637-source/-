# 恩睿视频采集助手

该 Manifest V3 插件与项目的编导灵感页面配合使用. 用户可以在项目中粘贴视频链接自动采集, 也可以在原视频页面点击插件图标后选择"采集当前视频".

## 本地安装

1. 解压发布包.
2. 打开 `chrome://extensions`.
3. 开启开发者模式.
4. 点击"加载已解压的扩展程序", 选择解压后的 `browser-extension`目录.
5. 打开插件面板, 确认应用地址为 `http://127.0.0.1:8080`.

## 使用条件

- 在浏览器中登录需要采集的视频平台.
- 支持抖音, 小红书, 快手, TikTok 和普通 HTML5 视频页面. 抖音精选搜索链接会通过 `modal_id` 自动转换为视频详情页.
- 支持 MP4, MOV, M4V 和 WEBM 文件. 当前不合并 HLS 或受 DRM 保护的视频流.
- 插件不读取或上传平台 Cookie. 视频请求直接使用当前浏览器会话完成.
- 插件仅在执行采集任务期间监听目标标签页的媒体响应, 不记录其他标签页的访问数据.
- 从项目粘贴链接时, 插件会先注册媒体监听再在后台打开标准详情页. 临时标签页不会被切换到前台, 采集结束后自动关闭.

## 发布前配置

正式部署后, 在插件面板中把"应用地址"改为生产站点地址. 发布到 Chrome Web Store 前应将 `<all_urls>`权限收窄到生产站点和计划支持的平台域名.
