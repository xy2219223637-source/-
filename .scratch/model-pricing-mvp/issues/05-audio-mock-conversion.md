# 05: TTS 与 ASR mock 折算计费闭环

Status: ready-for-agent
Blocked by: 03
task_id: model-pricing-mvp-20261019-05

**What to build:** TTS 与 ASR 分别通过模拟音频生成/识别响应，保留可核验的字符或时长原始用量，按对应模型折算 Token 并完成扣账和展示。管理员分别配置模型当前费率，不混用两种服务的计量依据。

**Blocked by:** 03 — 图像 mock 折算计费闭环，复用其通用折算、快照和查询行为。

- [ ] TTS、ASR 各自选择契约允许的原始用量来源及折算比例，费用页保存/回显/API 校验一致；mock 声明仅为可控测试协议，不能当作已核实的厂商最低规格或计费规则。
- [ ] 模拟音频、文本、时间戳及原始用量经过同一计费路径；字符按原发送文本 Unicode code point 计数，音频时长使用可核验毫秒数，不能凭文本长度猜音频时长。
- [ ] TTS 和 ASR 分别完成身份、规则、预占、快照、折算、企业扣额、成员已用、订单与唯一流水；查询与页面区分原始数量、折算 Token 和 MOCK。
- [ ] 成功、无音轨/空素材、缺用量、部分结果、音频无效、超时不确定和确定无消耗分别可控验证；ASR 自动路由与备用路径不会隐式访问真实服务或切换计费模式。
- [ ] 模拟提交/轮询/临时存储均可控且本地化；清理失败可观测，不遗留真实外部对象；模拟轮询不算真实生成次数。
- [ ] 定向规则/API/事务/组件检查证明两种能力的账务及展示一致，失败和未知不误扣或误释放，三次真实预算保持不变。

**Evidence:** 对应 AC03、AC05–AC08、AC13；分别提供 TTS 与 ASR 的端到端 mock 结果，不以其中一个通过代替另一个。
