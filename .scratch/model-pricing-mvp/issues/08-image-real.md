# 08: 图像真实接入与账务核对

Status: ready-for-agent
Blocked by: 06
task_id: model-pricing-mvp-20261019-08

**What to build:** mock 全流程通过后，对当前选中的图片供应商使用最低有效规格生成，验证有效图片、真实用量或折算依据，并核对企业与成员账务和页面展示。

**Blocked by:** 06 — 完整 mock 验收与真实调用门禁。

- [ ] 从实际运行配置确认活跃供应商、模型及质量设置，依据该厂商官方协议确定最低有效质量/尺寸/张数；当前高质量配置不能未经检查直接当成最低费用测试规格，不顺便测试备用供应商。
- [ ] 将真实协议及必要的适配改动先反映到 mock 场景，重跑受影响检查并刷新阶段报告；不允许以低费用为由绕开未通过的 mock 门禁。
- [ ] 同供应商＋模型＋图像能力最多三次最低有效请求，失败、重试和逐张子请求均计入；只在持久计次成功后调用，不自动增加张数或质量。
- [ ] 校验有效产物及真实计量证据；按已选模式使用真实 Token 或经确认的折算规则，数量及规格不符时不伪造产出用量；不明结果进入待核对，不能自动免费或重复生成。
- [ ] REAL 订单快照、企业扣额、成员增加额、唯一消费流水与查询页面一致；显示真实/折算来源及供应商成本或未知，和 mock 数据明确区分。
- [ ] 涉及临时素材与对象只操作本轮明确归属资源并验证清理；报告接入与计费各自结论、最小参数、次数、产物及脱敏账务证据，失败如实记录。

**Evidence:** 对应 AC06–AC10、AC12–AC13。不存在厂商价格/用量证据时不得用规范示例值冒充真实费用；只报告实际执行的验证。
