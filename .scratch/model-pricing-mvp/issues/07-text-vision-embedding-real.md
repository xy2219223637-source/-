**What to build:** mock 全链路通过后，将推理、视觉和嵌入分别接到当前已配置的真实服务，用厂商允许的最低有效规格验证返回及实际计费链路；消费页面能查看真实来源用量和账务，不将模拟用量冒充实测。

**Blocked by:** 06 — 完整 mock 验收与真实调用门禁。

- [ ] 真实执行前核实所连后端/测试环境、实际加载模型身份、厂商官方协议、最低有效参数和用量来源；endpoint ID 不等于已证实模型价格，不擅自扩大到未选备用模型。
- [ ] 如适配代码、用量规则或契约发生变化，先更新并通过受影响 mock 检查，刷新阶段报告；报告未通过时真实请求数量必须为零。
- [ ] 推理、视觉与嵌入各自以有界最小输入、最低有效规格调用；同供应商同模型同能力合并最多三次，失败、隐式重试及批量子调用计入；不因新运行或换票重置计数。
- [ ] 文本/视觉返回与嵌入向量分别通过有效性检查；提取真实 usage 并验证适用方向，不能用猜测 Token 或无输出方向的伪造零补齐；拿不到可靠用量进入待核对。
- [ ] REAL 订单使用开始时价格快照，同事务企业扣额、成员已用、唯一流水与查询展示一致；同意图重放不再调厂商或扣账，原业务权限不被 mock 权限替代。
- [ ] 成本有厂商实际证据才记金额及币种；无证据显示未知，同时展示 Token、真实执行模式与独立结算状态，不展示模拟无厂商费用。
- [ ] 分别输出三种能力的接入与计费结论、请求标识、计次、最小参数摘要、产物有效性及脱敏账务差额；未配置/失败/待核对不得记通过。

**Evidence:** 对应 AC06–AC10、AC12–AC13。操作仅针对已确认测试环境；配置写入、迁移、重启仍遵循已有授权边界，不隐式启用 worker 或开放全局隔离。
