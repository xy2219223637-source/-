# 01: 按模型 ID 管理当前 Token 费率

Status: ready-for-agent
Blocked by: None
task_id: model-pricing-mvp-20261019-01

**What to build:** 平台管理员在现有费用页查看脱敏模型清单，按模型 ID 保存和查看一套当前 Token 费率，刷新后仍能读到相同配置。模型类型仅分类，不新增能力定价或费率版本操作。完成从持久化、管理接口到页面及定向测试的完整路径，不调用真实模型。

**Blocked by:** None (can start immediately).

- [ ] 模型身份按供应商与精确模型 ID 去重；同模型多个能力共用费率，不同供应商同名模型区分；视频显示未实现，旧 mock_fixed/mock_text 不出现在可编辑模型清单，不暴露凭据。
- [ ] 完成 API 契约的三个模型费率目标操作及对应页面：分页清单、模型详情、幂等完整保存；沿用现有认证与平台管理员权限，缺权限拒绝，不能由客户端更改供应商、模型身份或提交结算用量。
- [ ] 输入/输出 Token 费率支持适用方向分别设置；为后续折算模式预留契约已定义的数据形状。重复计量项、额外字段、零/负费率、溢出、布尔冒充整数等输入被拒绝；说明示例不自动写入真实配置。
- [ ] 每模型仅一套当前规则，保存后对新请求生效；同键同体重放返回原响应且不再次覆盖价格，同键异体/异模型冲突，不同键并发保存按串行提交顺序生效，并保留审计。
- [ ] 费用页与旧费率列表契约同批升级，移除旧版本创建/启用流程；三个旧版本管理操作按规范停用。保留模拟传输与后续同模型 mock 验证能力，不把停用旧版本理解为跳过 mock 阶段。
- [ ] 当前价格持久化不放松历史价格、订单、流水或审计的不可变保护；迁移先有可审阅草案、预检查、备份与恢复验证方式，未取得对应环境写入授权不应用。
- [ ] 定向低层/API/组件检查覆盖保存与刷新、金额边界、鉴权、幂等、并发和旧历史读取；默认不做全量构建或 E2E，所有厂商及真实存储调用为零。

**Evidence:** 对应主规范 AC01、AC02（管理部分）、AC03（费率部分）、AC04、AC05（管理部分）、AC11、AC12。完成时记录实际检查结果、数据库环境脱敏标识及剩余限制，不冒充已跑通消费链路。
