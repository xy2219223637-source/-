# 02: 文本与视觉 mock 计费闭环

Status: ready-for-agent
Blocked by: 01
task_id: model-pricing-mvp-20261019-02

**What to build:** 使用同一模型 ID 和当前费率发起文本/视觉模拟消费，从身份与预占，到可控响应的 Token 用量、企业积分扣费、成员已用额度、流水、消费查询与页面展示完整跑通。mock 只替换外部传输，不建立第二套账本。

**Blocked by:** 01 — 按模型 ID 管理当前 Token 费率。

- [ ] 文本与视觉共用真实模型身份映射及当前费率，可返回不同的可控 mock 用量；保存执行模式 MOCK，页面显式标模拟，不把模拟 Token 当作厂商实测用量。
- [ ] 模拟请求通过既有业务权限及可信成员上下文；调用前持久化幂等意图、模型身份、费率快照和预占。无上下文、无价、无额度或无法确定用量上界时不调用适配器。
- [ ] 成功后同事务扣减企业余额、增加发起成员已用额度、写唯一消费流水并释放剩余预占；重复请求不重复调用或扣账；其他成员不被增加用量。
- [ ] 订单开始后调价，原订单仍按原快照结算，新订单使用当前费率；成功、确定无消耗、超时不确定、未知用量及超预占分别按规范处理，未知不当作免费成功。
- [ ] 完成四个模型订单查询目标操作，并在现有成员/企业消费页面展示 MOCK 模式、真实/折算来源、预占与结算状态；本人及租户边界正确，越权对象隐藏。MOCK 供应商成本显示“模拟，无厂商费用”。
- [ ] 替换旧 mock_fixed/mock_text 独立计价消费入口，按规范停用旧操作，但保留同模型 mock 完整验证。既有历史订单及其查询仍可回读。
- [ ] REAL 在 mock 报告缺失、无效或未通过时硬性拒绝；不能通过客户端切换执行模式，也不能因 mock 失败自动访问真实厂商；MOCK 不访问真实对象存储、不消耗真实三次额度。
- [ ] 先执行定向单元/API/事务/组件检查：两种模拟能力的成功、调价、重放、余额不足、事务回滚、越权及未知状态均有订单、用量、余额、成员、流水与查询断言。

**Evidence:** 对应 AC02（订单与旧 mock 部分）、AC05–AC08、AC11–AC13。交付逐场景结果及脱敏订单/流水引用；本票通过只证明 mock 链路，不证明真实接入通过。
