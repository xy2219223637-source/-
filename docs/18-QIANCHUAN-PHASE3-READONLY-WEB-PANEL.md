# 千川全域推广 Phase 3：只读网页联调面板

更新时间：2026-09-23

## 已落地

- 在成片详情的“千川素材反馈”区域加入 `QianchuanPlanCatalog` 旁路组件。
- 组件首先读取服务端能力门；`QIANCHUAN_PLAN_ENABLED=false` 时完全不渲染，也不读取账号。
- 开启后按“本人投放账号 → 授权抖音号 → 可投商品”顺序读取。
- 切换账号会清空旧抖音号、商品和选择结果；切换抖音号会清空旧商品结果。
- 使用请求序号丢弃晚到的旧响应，避免快速切换时显示上一个账号的数据。
- 商品支持平台 cursor 继续加载；关键词和抖音号条件会随请求传递。
- 页面只展示选择结果和能力门结论，没有创建、提交、启停或删除计划的按钮。
- 能力接口关闭、不可用或后端版本较旧时，旁路组件保持隐藏，不影响原素材上传和报表页面。

## 本地开启方式

仅为只读网页联调设置：

```text
QIANCHUAN_PLAN_ENABLED=true
QIANCHUAN_PLAN_WRITE_ENABLED=false
QIANCHUAN_PLAN_WORKER_ENABLED=false
```

修改运行环境后需要重启后端。打开任一已有成片详情，在“千川素材反馈”区域查看“千川计划目录（只读测试）”。

## 验证

```text
前端组件测试：12 passed
TypeScript project build：passed
Vite production build：passed
真实计划写请求：0
```

当前真实测试账号的只读探测结果仍是 0 个授权抖音号、0 个可投商品。因此网页能够验证能力门、账号选择、空状态和错误状态；要验证完整的非空选择交互，还需要一个确实存在授权抖音号与可投商品的本人测试账号。
