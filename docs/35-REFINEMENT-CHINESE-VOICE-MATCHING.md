# 视频精修中文音色与自动适配

## 音色目录

- 使用2026-10-13登录火山引擎控制台后核对的 TTS 2.0 中文相关目录.
- 提供276个真实音色ID, 包含110个女声音色和166个男声音色, 包含支持中文的混合语言音色.
- 保存目录至 `backend/app/services/data/refinement_chinese_voices.tsv`, 资源为 `seed-tts-2.0`.
- 仅允许使用目录中的ID. `/api/video-refinements/voice-options` 需要登录鉴权.
- 目录是控制台可见集合快照, 不是276个音色逐一成功合成的证明. 账户权限和额度仍由实时合成接口校验.

## 选声规则

- 默认自动适配, 仅为已启用且需要 TTS 的新增或改写台词触发选声.
- 遵循 `单段指定音色 > 任务指定音色 > 自动适配` 的优先级.
- 对同一个原片、精修目标和自动配音台词集合统一选声, 避免多个补充段音色跳变.
- 保留未修改区间的原配音, 不生成原声克隆或声音复刻.
- 在任务目标编辑中设置整体音色, 在方案编辑中覆盖单段音色. 支持名称和ID搜索、男女音色筛选.
- 修改台词或单段音色后清空旧配音绑定. 后端同样拒绝绑定不符合指定音色的配音.
- 展示实际生成音色、选声依据和生成后的试听入口.

## 自动适配依据与限制

- 从可信 ASR 台词区间抽取最多3段、每段最多4秒的真实音频, 本地测量声区和台词语速.
- 使用真实原视频关键帧、商品事实、原台词和新增台词, 由现有视觉模型在276个ID中选择音色.
- 音高不是身份、年龄或生理性别识别. 音色目录只有名称和类别, 不含每个音色的完整声学样本; 这是声区与内容风格级适配, 不是精确声纹匹配.
- 无可靠语音区间、测量不可靠或已知有背景音乐时, 标记为仅按内容选声, 语速保持正常值.
- 模型或媒体读取失败时明确报告失败, 用户可重试或手动选择, 不静默使用固定女声.
- 自动适配需要已配置的真实 AI 服务. 未进行真实付费 AI 或 TTS 合成验证.

## 缓存与一致性

- 选声缓存包含原片内容哈希、目标、新增台词集合、目录版本和适配版本.
- 优先复用方案中的有效选择, 再检查本任务已有配音的选择元数据. 台词或目标变化使缓存失效.
- 音频指纹包含实际音色、资源和语速, 不包含解释文字. 可复用相同声音参数的音频, 同时更新选声依据.
- 自动选声完成后重新检查草稿版本和哈希, 草稿变化时拒绝为旧方案排队生成.

## 验证命令

在仓库根目录执行后端测试:

```bat
backend\.venv\Scripts\python.exe backend\scripts\run_refinement_tests.py
```

在 `frontend` 目录执行前端测试与类型检查:

```bat
npm run test:lineage -- tests/video-refinement.test.tsx tests/refinement-voices.test.tsx
npm exec tsc -- -b --pretty false
```

覆盖目录完整性、非法音色拒绝、真实采样测量、内容选声限制、缓存失效、手动优先级、多段统一音色、旧绑定拒绝和草稿并发变化. 临时独立页面验证桌面与390px布局及44px控件尺寸; 实际精修详情页因平台登录失效未完成登录态端到端验证.
