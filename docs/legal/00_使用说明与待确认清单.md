# 注艺星擎 SaaS 平台协议包

> 适用现状：当前网页端主要供企业管理员创建的企业账号使用，提供电商商品素材、AI 图文与视频创作、生产协作及可选第三方平台连接。个人自助注册、个人付费及自动续费尚未开放。
>
> 运营主体：杭州美势文化发展有限公司。文档性质：产品与法务评审初稿。签约主体、商业数字和服务承诺须由双方确认。本包按当前代码修订；仍需核验的运营事实和未上线流程，在对外发布前必须由业务负责人补齐，并由法务结合实际业务、资质、数据流和交易流程复核。

## 一、文件清单

1. 《用户服务协议》：全体注册用户适用。
2. 《隐私政策》：全体自然人用户适用。
3. 《付费服务规则》：购买套餐、积分、次数包或订阅服务的用户适用。
4. 《AI 服务规则》：使用文本、图片、音频、视频、数字人等生成或编辑功能的用户适用。
5. 《企业及团队服务条款》：企业或团队工作空间的所有者、管理员和成员额外适用。
6. 《第三方服务与 SDK 清单》：披露短信、支付、云存储、统计分析及第三方模型等外部服务。
7. 《协议落地矩阵》：供产品、设计和研发确定展示、勾选、留痕及再次确认方案。
8. 《企业 SaaS 服务合同》《企业服务订购单》《服务等级协议（SLA）》《数据处理协议（DPA）》《信息安全与保密附件》《实施与验收单》：大企业签约及实施文件，仅在签署或订购单明确启用后适用。

## 三、建议采用的默认立场

- 用户上传内容仅获得“为提供、维护和改进其所请求服务所必要”的有限授权，不默认取得广泛商业化使用权。
- 平台不主动将用户输入、上传素材或生成结果用于自身模型训练；第三方模型供应商的使用范围须在启用前通过合同及实际配置核验，若无法满足该要求，不应作出禁止训练的对外承诺。
- 平台默认将素材及生成结果存入配置的阿里云 OSS；仅指定企业的视频可配置私有 S3。项目数据库、缓存与日志仍由平台处理，清理期限须经配置和运行验证。
- 项目数据在账号存续期间用于持续服务；删除与注销入口尚未实现，应上线前提供可执行的申请和处理流程；不得表述为不可删除、不可撤回的绝对永久保存。
- 涉及人脸、声纹等敏感个人信息时，在具体功能入口进行单独告知并取得单独同意。
- 若未来启用自动续费，必须由用户主动开通，并在扣款前以显著方式提醒；不把续费同意与基础注册捆绑。
- 对消费者不使用“任何情况下均不退款”“平台永不承担责任”等绝对表述。
- 企业管理员权限须在创建或交付成员账号时向企业与成员清楚展示；当前不是成员自主注册/加入流程。

## 四、版本与留痕建议

每份协议页面至少展示：协议名称、生效日期、最近更新日期、运营主体和下载/保存入口。后端仍建议留存内部协议版本、用户 ID、企业 ID（如有）、勾选时间、IP/设备摘要、触发页面、确认方式及协议正文哈希值，内部版本无需在公开页面展示。
