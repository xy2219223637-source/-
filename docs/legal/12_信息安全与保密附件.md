# 注艺星擎信息安全与保密附件

签署日期：以双方实际签署记录为准

本附件由客户与杭州美势文化发展有限公司签署，作为《注艺星擎企业 SaaS 服务合同》或《企业服务订购单》的专项附件。双方应仅勾选已经具备、能够持续执行并可验证的安全能力，不得将规划中的能力写成现有承诺。

## 1. 安全责任边界

1.1 服务提供方负责其控制范围内的应用、接口、服务账号、传输链路、运行环境和运维活动的安全。  
1.2 客户负责其成员账号、终端、内部网络、管理员授权，以及实际启用的私有 S3 视频存储、API 调用程序及其密钥、备份和生命周期配置；单点登录仅在专项开发并验收后适用。  
1.3 双方共同负责接口对接、权限最小化、异常处置、人员变更和安全事件协作。  
1.4 具体责任以资产和控制权归属为基础判断，不因系统部署位置或单一技术名义当然转移。

## 2. 访问控制

- [ ] 管理员与普通成员权限分离。
- [ ] 支持最小必要权限配置。
- [ ] 高权限操作保留审计记录。
- [ ] 管理员或运维访问经过身份核验和授权。
- [ ] 离职、调岗或权限变化能够及时回收访问。
- [ ] API Key、OSS 密钥及其他凭证不以明文写入公开代码或文档。
- [ ] 多因素认证、单点登录及 IP 限制当前未见已开放实现；如列为采购要求，须在订购单和实施单约定开发及验收。

客户应指定有权管理员并定期复核成员、角色和第三方集成权限。服务提供方不得绕过客户授权访问实际启用的客户私有 S3 视频存储，但为依法处置紧急安全风险且法律允许的除外。

## 3. 数据和传输安全

| 控制项 | 约定或现状 |
|---|---|
| 传输保护 | 正式环境应使用 HTTPS/TLS；实际证书、内部链路和对象存储传输配置须验收 |
| 平台侧存储保护 | 平台使用数据库和阿里云 OSS；加密、访问策略、备份须按生产配置验收 |
| 密钥和凭证管理 | 密钥置于服务端配置或专用密钥机制；轮换、权限和泄露处置须按环境验收 |
| 日志脱敏 | 核验鉴权令牌、密码、模型密钥和个人信息不会以明文写入日志 |
| 数据备份 | 数据库和对象存储备份范围、频率及恢复测试须按生产配置记录 |
| 临时缓存清理 | 对象缓存有配置项；各视频、模型任务临时文件仍须逐链路验证 |
| 数据隔离方式 | 以租户标识和权限控制分离数据；须验证跨租户访问隔离 |
| 数据导出保护 | 仅授权角色可导出；批量导出与审计机制若未实现须列为交付条件 |

3.1 仅在启用客户私有 S3 视频存储时，客户配置该存储的区域、访问策略、备份、版本和删除规则；平台阿里云 OSS 由服务提供方管理。  
3.2 服务提供方仅在任务处理所必要范围内访问实际启用的客户私有 S3，并应按照订购单和数据处理协议清理临时数据。  
3.3 **服务提供方不主动将客户数据用于自身模型训练；第三方模型的数据使用范围须依据合同与实际配置核验。**

## 4. 开发与漏洞管理

- [ ] 生产、测试和开发环境采取合理隔离。
- [ ] 代码和依赖变更经过评审或自动化检查。
- [ ] 建立漏洞接收、评估、修复和验证流程。
- [ ] 高风险漏洞修复目标由双方在订购单或安全计划中按风险级别约定；未约定前不得宣称固定时限。
- [ ] 第三方依赖和镜像具有更新或风险管理机制。
- [ ] 测试环境优先使用模拟数据或去标识化数据。
- [ ] 上线变更具备审批、回滚或应急处置方案。

涉及渗透测试、源代码审计或扫描的，应事先书面确定范围、时间、方式和安全措施，不得影响其他客户或生产服务。

## 5. 日志、监控与审计

5.1 服务提供方应对身份认证、高权限操作、关键配置变更、接口异常和安全事件保留必要日志。  
5.2 日志保存期限和客户可查询/导出范围须以生产配置与产品能力核验，并写入订购单。  
5.3 日志应限制访问，不得记录无必要的完整敏感信息、明文密码或完整密钥。  
5.4 客户申请安全审计时，应遵循最小影响原则，不得要求披露其他客户数据、平台密钥或会显著增加攻击风险的信息。  
5.5 现有安全认证、测评或报告仅可列经核验的证书或报告；目前模板不作已取得认证的声明。未取得的认证不得表述为已经取得。

## 6. 安全事件响应

6.1 安全事件包括数据泄露、篡改、丢失、未经授权访问、恶意代码、凭证泄露、拒绝服务以及可能影响服务或数据安全的其他事件。  
6.2 发现安全事件的一方应立即采取隔离、凭证轮换、访问阻断、备份保护和证据保存等合理措施。  
6.3 服务提供方确认事件影响客户后，应及时提供初步通知；具体小时数与渠道须在订购单约定，并持续补充已知影响、处置措施和后续计划。  
6.4 双方应配合监管报告、个人告知、根因分析和整改。未经协商，不得以对方名义发布信息，但法律要求的除外。  
6.5 事件责任按照原因、控制范围、过错及主合同确定，不因通知或协助行为当然推定责任。

## 8. 保密信息

8.1 “保密信息”包括一方向另一方披露的技术、产品、算法、模型、源代码、数据、报价、采购、经营、客户资料、个人信息，以及依性质或披露情形应当合理认定为保密的信息。  
8.2 接收方仅可为履行合同使用保密信息，并仅向确有知悉必要且承担不低于本附件保密义务的人员披露。  
8.3 接收方应采取不低于保护自身同类重要信息的合理措施保护保密信息。  
8.4 下列信息不属于保密信息：接收方能够证明已合法公开、披露前已合法掌握、从无保密义务的第三方合法获得或独立开发的信息。  
8.5 依据法律或有权机关要求必须披露时，接收方应在法律允许范围内提前通知披露方，并将披露限制在必要范围。  
8.6 合同终止后，保密义务持续双方在订购单约定的期限；未约定时在信息仍具保密性质期间持续；构成商业秘密或依法需要持续保护的信息，在其仍具备相应属性期间持续有效。

## 9. 人员与第三方管理

9.1 双方应对可能接触保密信息或生产系统的人员进行必要的安全和保密教育。  
9.2 服务提供方使用子处理方或分包方时，应按照主合同和数据处理协议履行审批或通知义务，并通过合同约束其安全与保密责任。  
9.3 任何第三方访问均应具有明确目的、限定范围和可撤销的授权。  
9.4 人员离职、角色变化或合作终止时，应及时回收账号、凭证、设备和资料。

## 10. 终止与资料处理

10.1 合同终止或处理目的完成后，双方应按照主合同和数据处理协议返还、删除或继续依法保管相关资料。  
10.2 客户私有 S3 中的视频对象由客户自行管理；平台存储数据由服务提供方依合同管理；服务提供方应撤销其控制范围内的访问并清理临时凭证。  
10.3 因备份轮换暂时无法立即删除的残留副本，应限制访问并在订购单约定且经备份周期核验的期限内完成覆盖或删除。  
10.4 一方可以在合理范围内要求对方提供删除或返还的确认记录。

## 11. 有效期和优先级

11.1 本附件自双方签署且订购单启用之日起生效。  
11.2 本附件在信息安全和保密事项范围内优先于主合同的一般约定。  
11.3 未约定事项按照主合同、数据处理协议和适用法律执行。
