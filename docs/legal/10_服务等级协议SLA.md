# 注艺星擎服务等级协议（SLA）

签署日期：以双方实际签署记录为准

本协议由客户与杭州美势文化发展有限公司签署，仅在《企业服务订购单》明确启用后，作为《注艺星擎企业 SaaS 服务合同》的专项附件。目标可用率、支持时段、故障响应和补偿等商业数字须在订购单中确定；未填写或未经双方确认的数字不构成服务承诺。

## 1. 服务范围

1.1 本协议适用于订购单列明且由服务提供方控制的注艺星擎企业 SaaS 网页端及对应 API。当前可包括企业账号和权限、商品与品牌资料管理、AI 文案与图片创作、视频分析与剪辑、分镜生产及任务管理；具体范围以订购单和实际验收结果为准。
1.2 千川、飞书、模型、语音、阿里云 OSS 及客户私有 S3 等第三方服务发生故障时，服务提供方应在控制范围内排查、协调与减损。是否纳入整体可用性指标及责任分担，须在订购单明确。
1.3 定制开发、私有化部署、单点登录及专项接口仅在订购单和《实施与验收单》明确并验收后适用本协议。

## 2. 可用性计算

2.1 目标可用率、统计周期和监测口径以订购单为准。未约定目标可用率时，服务提供方承担合理运维和故障处理义务，不得推定已承诺固定百分比。
2.2 约定可用率时，实际可用率＝（统计周期总分钟数－不可用分钟数）÷统计周期总分钟数×100%。不可用是指服务提供方控制范围内，已订购核心功能持续无法由已授权用户正常访问或提交任务，并经双方日志或监测证据确认的期间。部分非核心功能降级应单独记录。
2.3 计划维护、已提前通知并经订购单约定排除的窗口，以及客户网络、终端、凭证、客户私有 S3 配置或客户操作造成的不可用，不计入服务提供方不可用分钟数。第三方故障是否排除，按第 1.2 条及订购单约定，不得以第三方名义当然免责。
2.4 监测起止时间、时区、取整规则、证据来源及争议核对方式须在订购单或双方确认的运维记录中明确。

## 3. 故障等级与响应

| 等级 | 判定参考 | 响应与沟通 |
|---|---|---|
| P1 严重 | 核心服务整体不可用，或确认发生重大数据安全事件 | 立即启动应急处理；首次响应、更新频率与升级联系人以订购单约定 |
| P2 高 | 主要业务流程不可用且无合理替代方案 | 按订购单约定的支持时段、首次响应和更新频率处理 |
| P3 一般 | 部分功能异常，有替代方案或影响有限 | 记录工单并按约定优先级处理 |
| P4 咨询 | 使用咨询、非阻断缺陷或改进建议 | 按常规支持渠道处理 |

3.1 “响应”指受理、确认影响并开始排查，不等于修复完成。恢复目标、RTO、RPO 仅在订购单或《信息安全与保密附件》中经生产能力验证后明确承诺。
3.2 客户应提供发生时间、账号或租户、任务编号、错误信息和可复现步骤，并避免在工单中直接提交密码、完整密钥或无关个人信息。
3.3 服务提供方应在可行范围内提供绕行方案、进展更新和事后原因说明；重大安全事件的通知另按 DPA 和《信息安全与保密附件》执行。

## 4. 维护与变更

4.1 计划维护的通知提前期、维护时段和最长窗口以订购单约定。紧急安全修复可先实施，并在风险允许后及时告知。
4.2 可能实质影响已购核心功能、数据访问或接口兼容性的变更，应按主合同通知并提供合理迁移或减损安排。

## 5. 支持渠道

5.1 支持时段、工单或联系人、紧急联系方式及双方升级联系人须在订购单填写并保持可用。当前产品没有可据以承诺的统一在线工单或全天候支持机制。
5.2 未约定 7×24 小时支持、驻场或专属人员的，不推定服务提供方提供该等专项服务。

## 6. 服务补偿

6.1 如订购单约定目标可用率及补偿规则，客户可依据双方核对的监测记录提出申请。补偿形式、阶梯、申请期限、抵扣方式及是否计入同一事件的损害赔偿，均以订购单明确约定为准。
6.2 未约定具体补偿规则时，双方依主合同和法律处理违约及损失，不因本协议存在而自动产生服务费抵扣，也不排除依法应承担的责任。
6.3 故障或补偿争议不影响客户依法申请数据导出和行使个人信息相关权利。

## 7. 生效与优先级

7.1 本协议自双方签署且订购单明确启用之日起生效，适用于订购单约定的服务期限。
7.2 本协议在服务等级事项范围内优先于主合同的一般约定；数据安全、个人信息和保密事项分别按 DPA 与《信息安全与保密附件》处理。
