# 注艺星擎第三方服务与 SDK 清单

更新日期：2026年9月22日

当前项目可接入对象存储、模型推理、语音服务、飞书通知和巨量千川授权/API；未发现短信验证、在线支付、第三方账号登录、营销统计或独立客服 SDK。正式上线前，本清单应依据代码、网络请求、供应商合同和数据流实际填写；不得只按采购清单推测。

## 二、每个供应商必须核对的问题

1. 实际传输了哪些字段、文件和元数据；是否包含人脸、声音等敏感信息。
2. 第三方是受托处理者、共同处理者还是独立个人信息处理者。
3. 通过合同与技术配置确认第三方不得将提示词、上传素材、生成结果或企业数据用于模型训练；核对是否存在评测、人工审核或长期日志。
4. 存储地点、保存期限、删除接口、备份周期和跨境链路。
5. 是否允许转委托；下游供应商是谁。
6. 安全认证、加密、访问控制、事件通知和审计能力。
7. 用户关闭功能、撤回同意或注销后，第三方数据如何删除。
8. 供应商隐私政策、服务条款和数据处理协议是否与平台公开表述一致。

## 三、产品展示要求

- 隐私政策应链接本清单，并保持稳定可访问。
- 首次触发非必要第三方服务前，根据实际处理依据取得同意。
- 涉及向其他个人信息处理者提供敏感个人信息或跨境提供时，依法进行单独告知与单独同意。
- 第三方清单发生实质变化时，更新版本和日期；涉及处理目的、方式或种类变化的，依法重新取得同意。
