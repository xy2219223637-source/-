# 千川素材上传验证记录

日期：2026-09-14。范围：单条成片、单个已授权账户的文件上传与素材查询，不创建投放计划。

## 实现

- `POST /api/qianchuan/uploads`：校验租户、成片和账户归属，要求明确的 `is_aigc`，幂等入队，返回 202。
- `GET /api/qianchuan/uploads?video_asset_id=...`：本成片上传历史、素材 ID、视频 ID 和状态；刷新页面可恢复。
- `POST /api/qianchuan/uploads/{id}/retry`：发送前失败可重试（总尝试最多 3 次）；结果不明或已上传时只核验，不能直接重传。
- 新表 `qianchuan_uploads` 保存源 SHA-256、平台 MD5、目标账户、阶段和远端 ID。同一租户、成片、SHA-256 和投放账户唯一，重复点击复用任务。
- 复用单进程千川 Worker，并发上传 1。文件从既有 OSS 取回，校验 SHA-256 并复制到任务私有临时文件，以免缓存清理或文件变化影响上传。
- 先查询 A07 验证目标账户可访问，再调用 A06 multipart 上传。A06 返回素材 ID 后立即持久化，再调用 A07 在目标账户确认存在。平台查询不等于广告内容审核通过。
- 上传中断进入 `unknown`；最多 3 次自动核验后暂停。已收到远端 ID 时保持 `uploaded`，核验失败不丢 ID。重启后 `preparing` 可重排，`uploading` 只查询核验。
- 停用连接、授权版本变化或发起人权限失效阻止新的平台调用；已发送请求的返回 ID 仍保留。接近到期的 Token 交给既有账户同步流程刷新，再由用户重试上传。
- 首版产品限制为 MP4、不超过 50 MB；这不是平台最大文件限制。HTTP 连接超时 5 秒、读写超时 10 秒；上传流总发送时限 60 秒，查询分页时限 30 秒。未声称 SDK 注释中的平台 10 秒限制可被客户端绕过。

## 运行

授权连接新增“删除”操作（仅 owner）：`POST /api/qianchuan/connections/{id}/remove`。删除会清除本地 Token、使账户绑定与未完成授权失效，并从账户列表隐藏连接；保留历史上传记录及远端素材。已删除连接不能被旧回调、停用请求或重新授权请求恢复，需添加新的授权连接。前端删除当前所选连接时同步清空单选项。该操作不注销千川账户，也不撤销平台上的应用授权。

沿用 `backend/scripts/qianchuan_auth_live.py`：启动时建四张千川表并运行千川 Worker，不启动其他媒体 Worker。通用启动路径由 `init_db()` 建表。前端仍为 `127.0.0.1:5173`。

在成片页打开“推送到千川”，选择账户、填写素材名称和 AI 生成标记，再点击“上传素材”。页面显示任务阶段、历史记录和远端 ID。实际投放仍须在千川另行创建计划。

契约来源：官方 SDK 固定版本 `6122a5fe2096ddc673f1e7a553bc5d3437645025` 的 `FileVideoAdV2Api`、`FileVideoAdV2ResponseData`、`QianchuanVideoGetV10Api`、`QianchuanVideoGetV10Filtering` 与 `QianchuanVideoGetV10ResponseDataListInner`。查询响应视频 ID 字段为 `id`，上传响应视频 ID 字段为 `video_id`。
