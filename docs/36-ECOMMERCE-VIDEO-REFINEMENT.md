# 电商商品视频精修

## 业务边界

- 从电商商品管理关联的商品成片库选择被精修的源视频, 仅允许 `library_type=finished` 和 `asset_kind=final_output`.
- 只在视频精修页选择成片, 商品成片库列表和详情不提供精修入口. 按用户反馈移除精修页的分类与标签筛选区, 保留商品, 时长, 画幅和创建时间筛选, 标签搜索, 视频预览, 查看详情和下载. 分类, 公共标签和个人标签仍在商品成片库管理.
- 商品成片不提供素材复用状态管理, 精修不检查该字段, 历史 `blocked` 成片也可用于精修. 共享表仍保留该字段供商品素材使用, 无需修改历史成片数据. 独立的 `excluded` 标志仍用于排除不可用视频.
- 商品成片上传后只做文件校验, 补全时长, 分辨率, 帧率和内容哈希, 校验成功后保存为 `uploaded`, 不进入商品素材 AI 分析队列. 成片库不展示分析状态, 分析摘要, AI 内容标签或片段分析.
- 库内 AI 分析, 重分析和中断恢复只处理 `asset_kind=material`, 历史排队成片不触发分析. 精修任务内部按修改意见执行的分析, 配音, 渲染和预览确认流程保持不变.
- 从同一租户, 同一电商商品的商品素材库匹配替换或补充画面, 仅允许 `library_type=finished` 和 `asset_kind=material`.
- 在接受已核对的预览后, 创建 `EcommerceVideoAsset(asset_kind=final_output)` 并保存到商品成片库.
- 保留原成片, 通过电商精修版本及片段来源表记录源成片, 补充素材和输出成片. 已保存的精修成片可再次作为源视频继续精修.
- 对全部精修接口及导航使用 `ecommerce_assets.access`, 不要求旧成片库权限.
- 使用独立的 `ecommerce_video_refinement_*` 和 `ecommerce_video_lineage_segments` 数据表.
- 保留旧商品, 旧视频和旧精修工作台的数据, 仅通过显式迁移复制旧精修历史, 不在启动时自动迁移.

## 历史任务迁移

- 先完成商品素材和成片迁移, 使用 `source=legacy_video:<旧视频ID>` 建立映射, 禁止按文件名猜测对应关系.
- 从仓库根目录进行只读预检查, 核对租户, 旧任务数量和待复制记录. 使用实际租户和预检查返回的数量设置环境变量.

```cmd
backend\.venv\Scripts\python.exe backend\scripts\migrate_legacy_refinements.py --tenant-id %TENANT_ID%
backend\.venv\Scripts\python.exe backend\scripts\migrate_legacy_refinements.py --tenant-id %TENANT_ID% --expected-tasks %LEGACY_TASK_COUNT% --apply
```

- 迁移前将旧任务及关联记录备份到 `%TEMP%`, 保存命令返回的备份路径. 迁移采用单一事务, 重复执行跳过已迁移任务, 不覆盖现有电商任务.
- 复制任务, 快照, 修改意见, 方案, 配音, 预览, 已保存版本和片段来源, 重映射商品/视频/配音 ID, 地址及方案哈希. 保留创建和更新时间.
- 暂停迁移时仍在排队或运行的分析, 配音和渲染, 不自动调用 AI. 保留历史分析检查点作为记录, 禁止新任务复用旧资产指纹.
- 对已删除的历史素材保留原始修改项, 禁用失效绑定并展示具体阻塞原因. 未完成任务须重新选择商品素材, 不自动替换或掩盖缺失.

## 方案与时长校验

- 按目标自动规划和生成预览, 不逐项索要剪辑授权. 区分动作目标与保留限制, 允许一个剪辑项同时落实多条相关要求; 禁止拼接无关要求来扩大配音或插入权限.
- 将沿用原音频, 保留原配音和不生成新配音解释为音频来源限制, 允许同步裁切完整语义片段及其原音频. 只有明确完整保留全部台词时才检查口播实测时长与缩短目标的真实冲突.
- 在草稿进入素材和配音准备前校验目标, 授权, 限制和已有实测语音边界. 对越界, 未落实目标或截断台词的草稿自动重规划一次, 重新执行 schema, 依据和编译校验; 再次失败时保留媒体和素材评估检查点, 不缓存无效方案, 不转为用户澄清. AI 不得自行标记人工边界已确认.
- 仅展示有具体问题的真实冲突或必要信息缺失, 合并同一关联冲突的重复问题. 不以内部授权错误或缺少独立约束编辑项要求用户再次确认. 生成预览后仍须人工验收, 不覆盖源成片.
- AI 提示词明确要求时间区间为 `{start_ms,end_ms}` 整数毫秒对象. 对提供方返回的两端数组仅做无损结构转换, 不取整, 不猜测坐标或素材 ID.
- 提供完整修改项 JSON Schema, 仅在字段, 依据引用和方案编译通过后缓存 AI 草稿. 校验失败保存字段路径和错误类型, 不保存原始响应内容到诊断记录; 重试复用有效的素材匹配结果.
- 仅删减源片时使用空 `material_segments` 和 `narration_strategy=cut_source`, 禁止把源成片当作候选素材.
- 前后端均拒绝大于或等于原片时长的显式缩短目标. 未填写具体目标仍允许 AI 建议缩短方案. 修改已有任务时按最终生效的时长偏好校验, 无效目标不创建任务或增加版本.

## 部署

- 在启用新版精修 worker 前初始化新表. `RUN_DATABASE_INIT=true` 时, 后端启动会自动建表.
- 在关闭自动建表的部署中, 从仓库根目录执行以下命令, 然后重启后端. 脚本只创建缺失的新表, 不修改旧表或复制旧数据.

```cmd
backend\.venv\Scripts\python.exe backend\scripts\init_ecommerce_refinement.py --dry-run
backend\.venv\Scripts\python.exe backend\scripts\init_ecommerce_refinement.py
```

## 验证

```cmd
backend\.venv\Scripts\python.exe backend\scripts\run_refinement_tests.py test_refinement*.py test_video_refinement.py test_ecommerce*.py
```

- 验证跨租户隔离, 商品素材与商品成片隔离, 同 ID 的旧资产及旧任务隔离.
- 验证未预分析且 `blocked` 的商品成片可创建, 确认及接受精修任务, 商品素材的复用限制保持有效.
- 验证成片直接上传和分片校验不请求 AI, 旧排队成片不进入素材分析或恢复, 成片重分析接口拒绝请求.
- 验证分析缓存只读写电商素材分析表, 成片继承电商素材公共标签.
- 验证重复接受预览仅生成一条商品成片及一个精修版本.
