| 范围 | 结果 |
| --- | --- |
| 自动素材选段 | 从配音实测毫秒只计算一次整数帧预算, 各选段仅消费剩余帧数. 不先取整为毫秒再逐段向上取整. |
| 时间计算 | 在 `refinement_timing.py` 集中实现帧预算, 帧与毫秒边界转换, v2 技术尾差判定. |
| 末段修正 | 将缩短一帧的结果保存到方案的 `automatic_adjustments`, 包含素材 ID, 修改前后范围和说明. 修正后的区间重新核验与编译. |
| 编译与渲染 | 共用技术尾差函数. v2 只接受最多一帧加 1ms 的端点量化误差, 不启用全局 100ms 容差. |
| 画面末帧 | 调整 FFmpeg 滤镜顺序, 在时间裁切之前处理输出帧率, 避免人为 EOF 导致每段丢失末帧. 完整解码时验证实际总帧数. |
| 配音完整性 | 不按四舍五入的毫秒长度裁掉 TTS 尾部样本. 解码后的配音超过输出容量时阻塞, 即使只多一个样本也不截断. |
| 要求与阻塞 | 增加执行阻塞分类. 音频或内容阻塞不将可执行要求改成等待素材, 实际缺素材才使用 `AWAITING_MATERIAL`. 避免重复显示关联泛化错误. |
| 自动预览授权 | 移除自动写入的 `supplement_narration=tts`. 自动模式也执行纯画面默认规则, 用户原文和关联澄清回答作为授权依据. |
| 无讲话插入 | 保留明确无讲话展示的 `none` 策略, 不在自动素材准备阶段强制改成 TTS. |
| 缓存与哈希 | 更新意图解析和规划缓存版本. 新编译方案写入 `timing_version=v2-frame-budget-1`, 参与现有方案哈希并保存在渲染 recipe 中. |
| 前端 | 显示实际源选段和非阻塞的帧修正记录, 不再声称自动精修一定生成补充段配音. 新字段可选, 旧方案可读. |
